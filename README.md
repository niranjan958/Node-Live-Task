# Task Manager API (Node.js + Express + PostgreSQL + Sequelize)

A full-featured **Task Management REST API** built using:

- **Node.js + Express**
- **PostgreSQL**
- **Sequelize ORM**
- **JWT Authentication**
- **Auto Database Sync**
- **Modular Folder Structure**

This API allows users to register, log in, and manage tasks with priority & status filters.

---

## Features

### Authentication
- Register  
- Login  
- JWT-based authorization  
- Protected routes

### Task Management
- Create Task
- Get All Tasks
- Get Single Task
- Update Task
- Delete Task
- Linked with User
- Auto timestamps (createdAt, updatedAt)

### Additional Features
- Sequelize ORM + PostgreSQL
- Auto table creation (`db.sync({ alter: true })`)
